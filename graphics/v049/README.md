**Extraction:** Reference individual SVG, or edit its native geometry. Transparent frame SVGs do not contain an image background; the host supplies the media. Decorative frame overlay should use empty alt on an `img` element; meaningful pictograms need contextual alt. Icons are decorative visual cues, not interactive editor commands or an icon-font package. Dimension ticks in the technical frame are illustrative, not calibrated engineering measurements.
