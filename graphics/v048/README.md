**Style:** compact illustrated-color icon family with teal ink outlines, mint/coral/warm gold fills; unlike a monochrome `currentColor` UI icon pack. It is not affiliated with a game franchise; icons do not implement gameplay, points, prizes, store purchases or authentication.

**Reuse:** Import the individual SVG file or edit its vector shapes and colors. Respect `title`/`desc` and choose contextual `alt` for nondecorative usage; for decorative instances use empty `alt` on the host image element. Host project determines sizing, contrast, pixel density and interaction. No shared runtime dependency.
