# V0.43 · Six standalone original vector illustrations

**Six real, individual SVG files** with scalable `viewBox="0 0 640 360"` and original vector paths. They can be referenced with HTML `<img src="...">`, inlining after review, or adapted in design tools. They are not photographs, fonts, third-party vector packs, generated pages or asset-mirrored content.

All graphics authored as standalone local SVG **source assets**. Each SVG includes an accessible `<title>` and `<desc>` with unique local IDs inside its standalone file; when used purely decoratively, the target should set an empty HTML `alt` instead of repeating the caption. There is no `<image>`, external reference, CSS import, network dependency, JS, third-party icon set or embedded font. They use original geometry and colors rather than copying copyrighted upstream component artwork.

Preview as separate media tiles in [`playground/vector-studies-v043/`](../../playground/vector-studies-v043/). SVG `viewBox` supports scaling, but target app must check contrast and responsive cropping.
