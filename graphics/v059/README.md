# V0.59 · Independent original raster-inspired SVG artwork

These four vector images are hand-authored, independent **decorative artwork**. They have a 640×360 viewBox and accessible `<title>`/`<desc>`, no external fonts, font binaries, raster media or JavaScript. The artwork is not generated from real telemetry or image pixels. The related live ASCII field specimens are in [styles/primitives/v059](../../styles/primitives/v059/README.md) and are a separate capability.

| Stable ID | Source | Distinct design intent | Boundary |
| --- | --- | --- | --- |
| VG-107 | [raster-sunrise.svg](raster-sunrise.svg) | Stepped abstract sunrise and halftone sea reflections | Fictional decorative landscape, not weather, astronomy or real imagery |
| VG-108 | [bitstream-weave.svg](bitstream-weave.svg) | Crossed rectangular-pixel textile ribbons | Pixel motif, not encoded data, QR, bitstream/network information or machine-readable sign |
| VG-109 | [glyph-window.svg](glyph-window.svg) | Block-built art-deco arch onto imaginary night | Fictional decorative opening, no geographic/photo evidence or interactive portal |
| VG-110 | [stepped-prism.svg](stepped-prism.svg) | Floating pixel-step prisms with schematic contours | Optical pseudo-3D, not true 3D model or physically meaningful perspective |

All images are independently inspectable/editable text SVG. Use as informative media with a meaningful `alt`, or decorative media with an empty `alt`, according to the target context. Real browser display, reduced-motion integration, and host accessibility/contrast have not been certified.
