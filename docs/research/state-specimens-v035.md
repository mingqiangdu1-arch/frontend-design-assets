# V0.35 · 独立视觉状态样张和多屏构图证据（2026-11-10）

> **范围**：为 V0.34 已收录的 8 个研究资产新增原创静态 SVG 视觉样张。每个 SVG **只描绘单项素材的一组代表性状态及桌面/移动概念布局**，不是真实 1440/390 浏览器截图、不是整页 UI、不是可执行行为，也没有反映跨设备/无障碍实测。资产 ID 不变，总数仍为 255。

## 使用方法

Agent 先在 [研究型素材索引](../../registry/experience-artifacts-v034.json) 找原有模式与状态合同，再在 [本轮样张清单](../../registry/state-specimens-v035.json) 按 assetId 选一份 SVG。样张提供构图、相对优先级和状态区分的视觉线索；真实实现必须读 [V0.34 交互风险](experience-artifacts-v034.md) 并按目标设备做验证。

## 视觉与实现分界

- **REF-081 双线对照阅读**：不强制同步滚动；需独立锚点与 URL 逻辑。
- **REF-082 证据页边注**：注释锚点和回原文功能须在目标项目实现。
- **REF-085 非对称编辑网格**：图中卡片仅形状；不保证真实 subgrid 排版。
- **IP-042 星图与同名目录**：星图位置不是地图坐标；非运行导航。
- **IP-043 环形操作罗盘**：没有注册键盘、Pointer Events 或菜单命令。
- **IP-044 可恢复章节方位轨**：返回焦点和浏览器历史是设计约束，不是静态 SVG 的功能。
- **IP-046 逐帧探索的双状态**：不会实际拖动、播放视频或修改任何媒体。
- **IP-047 语义检查透镜**：不模拟真正放大镜；真实图层、数据和 focus 交由目标项目。

## 设计与数据不变量

- SVG 是**原创、无需外部媒体文件的示意图**；仅使用内联向量与系统字体，不含 JavaScript、远程 URL、字体二进制、第三方截图或真实商品/业务数据。
- 样张上的“desktop 1440”“mobile 390”指拟参考的目标视口，不是按该分辨率生成并测试的真实屏幕截图；所有图均固定 1000 × 450 viewBox，内嵌两种**示意**构图。
- 研究条目仍为 `analyzed / research-only`。即使可视化状态存在，也不能推断已实现焦点管理、恢复 URL、键盘等效操作、拖动或真实响应式 CSS。
- 配套 [V0.34 六个独立 CSS 构图原子](../../styles/primitives/v034/README.md) 是另一种代码资产；SVG 不等于 CSS 被实际渲染验收。
- 应用范围是前端素材研究与选材。不得借图像构图冒充地理坐标、数据显示、真实图层或生产界面。

## 选用与拒绝规则

选择本轮 SVG 的前提是想要**快速看清信息层级、状态区分与响应式取舍**。如需要交互行为或可复用代码，则先检索 `stage=prototype` 且有 `path` 的原型，或真实导出的 React 组件；不能以本轮素材替代。

## 完成检查范围

- 验证 SVG 文件存在、纯本地矢量、带 title/desc、无 remote URL/script/foreignObject、没有与现有 ID 冲突。
- 自动注册表与单元测试仅检查结构和标注边界；本轮未承诺真实浏览器可视比对、人工视觉审查、手机触摸或读屏测试。
