# Differentiated direction brief / 多方向视觉简报

Scenario: a reading-and-research archive, mobile and desktop, long Chinese text, with a small visual showcase.

| Dimension | A: Calm editorial | B: Typographic index | C: Material research notebook |
| --- | --- | --- | --- |
| Theme candidate | `editorial-warm` | `type-led-minimal` | `paper-rebellion` |
| Hero composition | readable masthead + narrow longform | oversized heading + numbered entry rail | note-like collage + anchored plain-text lead |
| Text and density | spacious readable line length | strong display contrast, compact index | varied annotations, clean body copy |
| Media | `FX-097` caption-first mosaic | `FX-094` offset cover | `FX-099` semantic field notes + `VG-088` pinboard |
| Interaction | reading and disclosure | explicit jump links, keyboard-friendly index | controlled reveal of supporting material |
| Risk | long CJK serif legibility | large type can crowd mobile | decorative notes can obscure content and DOM order |

Use real [style facets](../../../../../registry/style-facets.json) to corroborate the theme claims and actual source files for asset compatibility. This table proposes **directional mixing** and does NOT assert that the referenced CSS families are globally compatible with those styles or available as React components.

## Minimum output structure
1. Project task / audience / constraints (facts versus assumptions).
2. Two or three contrasting directions with a one-sentence mental image.
3. For each: dominant layout, typographic mood, materials, media, interactions and original reference IDs/paths.
4. Top failure mode and accessible/responsive alternative.
5. Decision tradeoff based on user task, **not** an absolute beauty or popularity score.

If a user asks for one committed design, recommend one conditionally while preserving the alternative tradeoff; continue to asset selection only after style intent is sufficiently grounded.
