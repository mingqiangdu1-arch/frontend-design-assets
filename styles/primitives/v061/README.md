# V0.61 · Original print and pattern atoms

六个独立原创源文件级素材，不复制 V0.60 上游代码。

| ID | Class | 实际能力 | 限制 |
| --- | --- | --- | --- |
| FX-130 | `fx61-loop` | 两个整数频率的原创参数曲线，滑杆改变阶数 3–11 并实际更新 SVG。 | 非物理测量、防伪或图案编辑器。 |
| FX-131 | `fx61-dither` | 96×64 数学明暗场经 4×4 阈值矩阵二值化，真实滑杆改变亮度偏置。 | 不处理照片或用户上传数据；非印刷校色。 |
| FX-132 | `fx61-ribbon` | 两组交叉重复渐变形成连续带状纹样。 | 装饰，不模拟实物织物或碰撞算法。 |
| FX-133 | `fx61-offset` | 两种偏置旋转剪影以 multiply 叠色。 | CSS 合成示意，非真实油墨校准。 |
| FX-134 | `fx61-chart` | 斜线、圆点、网格三种条图，明确类别、数值和共同量尺。 | 示例值虚构，真实数据须统一派生条宽及文本，非图表引擎。 |
| FX-135 | `fx61-proof` | 三种逻辑像素周期的排线，使用语义 DL 标注。 | 非物理网点密度或印刷认证。 |

[CSS](print-atoms.css) · [本地模块](print-math.mjs) · [语义样张](../../../playground/print-patterns-v061/index.html)。经 HTTP 静态服务打开；ES module 不保证 file:// 可用。按 class 提取，FX-130/131 挂载后调用 mountPrintAtoms 一次。无网络、计时器或外部依赖。FX-130 是整数谐波参数曲线；FX-131 为原创数学场加经典 4×4 Bayer 阈值矩阵。目标端仍需验证键盘、读屏、设备、Canvas 回退、真实图表数值及视觉。
