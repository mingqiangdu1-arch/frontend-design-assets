# V0.32 · 独立 CSS 视觉原子（非页面组合）

这个目录只储存**原创、显式 opt-in 的 CSS 小素材**。不会创建一个完整页面、默认主题或 React 组件，也不会引入字体、媒体文件、依赖或应用脚本。配套研究：[V0.32 视觉 / 编辑器专题](../../../docs/research/creative-primitives-v032.md)。

## 6 个可取用的小原子

| 类名 | 对应研究 | 可见效果 | 降级与使用警告 |
| --- | --- | --- | --- |
| `.fda32-print-grain` | `REF-074` | 两组低对比细微线纹，适合纸张底面 | 不是摄影噪声，避免覆盖密集正文 |
| `.fda32-halftone` | `REF-074` | 简单网点图案 | 禁止用网点独自表达数据值 |
| `.fda32-soft-edge-mask` | `REF-075` | 横向柔边图片/素材蒙版 | 不要用它隐藏真实权限内容，浏览器不支持时直接显示原始像素 |
| `.fda32-spectral-wash` | `REF-079` | 固定双径向光谱背景 | 仅作为装饰，需选择合适文本前景色 |
| `.fda32-once-reveal` | `REF-080` | 一次性短距离渐显 | `prefers-reduced-motion: reduce` 会移除动画 |
| `.fda32-optical-type` | `REF-069` | 对支持光学字号的字体启用其排印行为 | 不会加载或赋予任何字体许可；无 opsz 时不强制模拟 |

## 最小接入方式

独立目标项目在确定需要这类特效后，仅复制所选 class 的声明和必要的 keyframe。下面只演示调用**单一原子**，不属于仓库里的应用或页面：

```html
<div class="fda32-halftone" aria-hidden="true"></div>
```

`aria-hidden` 在此示例只适用于纯装饰元素；不要添加到实际有意义的图片或文本容器。组件结构、颜色对比度与交互语义由目标项目负责。CSS 原子不通过任何当前 React 主题兼容性声明。

## 移植时检查

- 类名全部以 `fda32-` 为前缀，不使用全局 `:root`，无外部请求。
- CSS 自定义属性提供局部配色，但不会引入或定义全局 design tokens。
- 仅 `.fda32-once-reveal` 具有有限时长的可选动画；不要直接应用到需要常驻输入焦点的元素。
- 支持对动画减少与高对比系统模式的降级；但**未**进行物理设备、读屏、浏览器矩阵或性能实测。
- 真实公开分发前仍需检查项目配色、浏览器兼容性与可读性。
