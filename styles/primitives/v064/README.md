# V0.64 · Original spatial composition atoms

六个独立原创可提取原件，取材方向来自 REF-157..164，未复制第三方实现。

| ID | Class / mode | 实际能力 | 既有区别 | 限制 |
| --- | --- | --- | --- | --- |
| FX-142 | `.fx64-seed` / seed | 两个可输入种子独立生成网格比例与六个视觉块顺序；单独递增任一 seed 不改变另一个结果。 | REF-157 研究转为独立原创简化原件；PR-012 是方向简报，FX-085 是数学图形。 | 固定六块与四列三行，非任意文档排版、内容生成、拖拽或布局导出。 |
| FX-143 | `.fx64-type` / type | 真实 DOM 三行文字通过有界水平偏移形成可调阶梯构图，保持阅读顺序。 | REF-158/159 是轮廓几何；此项不需要字体解析且保留 DOM。 | 固定示例文字；非真实字体轮廓变形、CJK 自动断行或任意包络编辑。 |
| FX-144 | `.fx64-arc` / arc | 五个可聚焦原生按钮，点击或键盘激活改变选中卡片与其他卡片的弧形偏移、旋转，输出名称。 | REF-162 的 WebGL 轨道简化为可操作 CSS 选中构图；不同于环形命令菜单。 | 固定五项原创 CSS 色块；非无限滚动、3D、WebGL、媒体下载或播放器。 |
| FX-145 | `.fx64-fit` / fit | 改变左侧工具面板的模拟遮挡比例，按剩余视口实时计算画板居中与缩放；ResizeObserver 跟随容器。 | IP-018 已有一般 pan/zoom；此项专门补充遮挡边距 fit。 | 固定单画板、只缩小不放大；无拖拽、滚轮、真实浮动工具窗或无限画布。 |
| FX-146 | `.fx64-linked` / link | 固定三个 SVG 元素与源码标签，通过两组原生按钮双向选择，统一高亮状态与名称输出。 | REF-164 提供真实复杂映射，本项仅为可提取联动模式，不重复通用属性检查器。 | 显式固定 ID 映射，不解析任意源码、不编辑 SVG、不提供真实 source map 或编译器。 |
| FX-147 | `.fx64-ribbon` / ribbon | 有界滑杆调整 SVG 二次曲线带状中部偏移，顶部/底部端点保持固定。 | REF-161 是 WebGL 弹性滚动；本项是原创低成本几何原件。 | 手动几何样本，无滚动驱动、弹簧动力学、纹理变形或 GPU 渲染。 |

[CSS](spatial-atoms.css) · [本地模型](spatial-model.mjs) · [语义样张](../../../playground/spatial-composition-v064/index.html)。HTTP 静态服务打开；提取选定 class、对应 data-fx64 HTML，挂载后调用 mountSpatialAtoms(root) 一次；卸载时调用返回的清理函数。画板模型只针对正值宽高，样张使用固定 240×150；不支持无效几何输入的任意宿主。按钮均为原生按钮，图形与标签显式同步，不宣称真实源码解析或字体轮廓运算。十项纯模型断言覆盖确定性、独立种子、排列、弧轨、fit 与固定端曲线；未执行新样张浏览器、设备、读屏或审美验收。
