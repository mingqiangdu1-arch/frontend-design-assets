# DT-009 · Paper Rebellion

手工拼贴 / Zine 杂志 — **independent experimental style proposal**, not a general-purpose SaaS theme.

## Design DNA

tactile paper layers, handcrafted annotations, readable primary blocks and controlled irregularity.

**Layout grammars:** overlapping torn note stack; asymmetric art-board with anchored copy; stamp annotated culture index.

**Typography:** oversized editorial display with handwriting accent; small print-run annotations; clear large body in plain sans. Body content stays readable even if display forms are expressive.

**Texture:** paper fibers simulated via CSS; tape/label stamps; offset shadow and freehand border.

**Motion:** short paper lift on interaction; gentle offset reveal; no constant shaking. Observe reduced-motion preferences; never convey state only via color or movement.

**Interaction:** rearrange collage rhythm; filter zine topics; peek behind note.

## Where it can be used

indie-magazine, artist-portfolio, culture-campaign, community-story, creative-workshop. A designer or model must still assess real task complexity, content density and operating constraints.

## Do NOT use as

- illegible handwriting for essential text
- uncontrolled overlaps on mobile
- decorative paper hiding form labels
- borrowed scanned magazine art

**Specific caution:** Decorative scraps may overlap, but accessible reading order must stay predictable.

## Creative extrapolations

- collage for science outreach
- community archive with paper scraps
- artist process journal

## Usage & evidence

- [Interactive mini-scene](../../playground/creative-style-lab/index.html) with explicit scoped style; theme can be selected with `?style=paper-rebellion`.
- [Machine-readable creative brief](../../registry/creative-directions.json) and [deterministic art-direction CLI](../../scripts/creative-director.mjs).
- Independent Token JSON/CSS; **not** part of the four compatible themes of `packages/ui` React components.
- Illustrations and graphics are CSS-only original constructions; no external stock images, fonts, screenshot reproductions or source code.
- Not production-ready. Before adoption run text/controls contrast checks, responsive QA, true content, keyboards, assistive technologies and performance on physical devices.
