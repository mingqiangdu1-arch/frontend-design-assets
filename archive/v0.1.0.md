# Initial UI Kit V0.1.0 · Historical snapshot

The initial ChatGPT deliverable (2026-10-23) bundled:
- 60 baseline design values and original CSS theme;
- 9 React/TypeScript **reference** components;
- 8 interaction patterns and 3 page recipes;
- standalone HTML interaction lab and screenshots.

The initial artifact was created before this GitHub repository existed. **This GitHub initialization migrates its single-file interactive HTML demo, research/specifications, and 9 React/TSX component reference implementations. It does not preserve the previous ZIP byte-for-byte or include the old PNG screenshot set.** Retain this distinction when comparing versions.
