ASSEMBLY GUIDE

如何调用这些资产

先按 ID 检索，再确定交互状态、Token、依赖和页面组装方式。

资产调用流程

01 · 检索查看 registry/asset-manifest.json，根据 tags、layer、framework、status 匹配。
02 · 选取先引入 tokens/tokens.css，再挑选组件和交互模式。
03 · 组装对照 react/recipes/ 或 docs/page-recipes.md 拼装骨架。
04 · 验收核查 loading / empty / success / error / disabled / keyboard / mobile / reduced-motion。

现阶段范围

这是独立参考实现，不与现有业务代码耦合。React 适配器使用 TypeScript 和 Radix 对话框；纯 HTML 预览不依赖服务端或外部 CDN。更复杂的拖拽分栏与生产级 Toast/表格管理应在明确技术栈后接入经过验证的专业组件。
