# Trend Style Lab · four independent 2026 trend-led research scenes

These are **four distinct original HTML/CSS/JavaScript compositions**, not one dashboard with swapped Tokens and not four integrations of the React UI package.

| Scene / deep-link | Interaction | Distinct layout |
| --- | --- | --- |
| [Liquid Layer](index.html?style=liquid-layer) | Landscape mode and transparency switch | Open environmental field + floating navigation + opaque reading layer |
| [Shape Expressive](index.html?style=shape-expressive) | Three semantic task choices | Large asymmetric choice shapes + focus story |
| [Type-led Minimal](index.html?style=type-led-minimal) | Three indexed story modes + native disclosure | Oversized headline + index rail + TL;DR overview |
| [Organic Tactile](index.html?style=organic-tactile) | Three labelled material choices | Organic CSS object + earthy story + soft notes |

Run from repo root: `npm run dev:catalog`, then visit `http://127.0.0.1:8009/playground/trend-style-lab/`.

Use the theme switcher, keyboard tab/Enter, responsive browser widths and native controls. All scenes are local; browser URL deep links follow `?style=<id>` and work with Back. They render **original CSS illustration only** — no external product imagery, fonts or copied vendor source.

Testing: `npm run test:registry`, `npm run test:tokens`, `npm run test:unit` and `npm run test:browser`. Visual captures are review evidence only; not approved baselines or accessibility/production certification.

**Compatibility:** these four themes are independent visual proposals. They are NOT automatically valid for `packages/ui`'s four supported React scopes. Style boundaries live in `registry/styles.json`, asset maturity/aliases in `registry/assets.json`. For selection reasoning see [2026 trend research](../../docs/styles/trend-research-2026.md).
