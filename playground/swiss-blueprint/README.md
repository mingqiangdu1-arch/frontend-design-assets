# Swiss Blueprint · Standalone Specimen (DT-015)

Independent interactive HTML/CSS/ESM specimen demonstrating the **Swiss Blueprint (`swiss-blueprint`)** visual direction: cyanotype cobalt drafting grid, drawing title block, interactive SVG schematic callout pins synchronized with a specification ledger, live `mm` / `in` unit conversion, and subsystem filtering.

## Run locally

```sh
npm run dev:catalog
```

Open `http://127.0.0.1:8009/playground/swiss-blueprint/`.

## Boundary

- Scoped exclusively via `[data-design-theme="swiss-blueprint"]` (no global `:root` injection).
- Illustrative synthetic part dimensions only; not certified CAD tolerances or a React component package theme.
