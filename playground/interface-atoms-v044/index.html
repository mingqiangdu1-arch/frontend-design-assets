如何使用

每个样张对应一段可复制的原生 CSS 源码与最小 HTML 标记，不是整个网页模板；单独搬运时保持原生交互语义、focus-visible、减少动效和强制颜色支持。某些示例数字及阶段仅为虚构展示，不代表真实数据或业务功能。
