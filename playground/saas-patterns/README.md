# SaaS Pattern Lab · v0.2

范围：工作台视觉层级与日常高频数据交互。全部是原始构建的模拟页面，而不是对任何第三方真实产品页面的复制。

```bash
# 在仓库根目录
python -m http.server 8009
# 浏览器
http://127.0.0.1:8009/playground/saas-patterns/
```

也可直接打开 index.html，但 `type="module"` 导入的本地文件受浏览器 file:// 安全策略限制，**推荐 HTTP server**。Codex/内置浏览器同理。

## 支持操作

1. 点击“全部/进行中/已完成”切换数据视图；
2. 搜索记录及点击名称、更新时间表头排序；
3. 标准/紧凑密度切换；
4. 勾选记录（含当前可见范围全选），批量本地归档后撤销；
5. 打开记录详情，修改名称、尝试空名称验证、取消/保存；
6. “状态预览”区域切换正常/加载/网络异常/空数据，观察清晰反馈与恢复；
7. 狭窄视口下表格在内容区滚动，详情使用单独层。

## 验证边界

- 纯状态逻辑由 `tests/saas-model.test.mjs` 覆盖。
- 项目 GitHub Actions 在新增的 Node 测试命令通过后，只能声明纯逻辑已通过，不等于浏览器交互、视觉、无障碍或生产集成已通过。
- 详情中的 Save、Archive、Undo 都是**模拟本地操作**，没有后端和持久化。
- 样例中的筛选“视图”是临时模式，不会真实保存工作区配置。
