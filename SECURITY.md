# Security and privacy / 安全与隐私

This project contains reference material, local demos and developer tools, not a hosted production service. No production security guarantee or service-level support is implied.

Report suspected vulnerabilities, exposed credentials or confidential material privately. If GitHub private vulnerability reporting is enabled, use the repository Security tab and **Report a vulnerability**. Otherwise use an established private maintainer contact; if none is available, do not publish exploit details or sensitive data in an issue.

Include the affected path/commit, impact, minimal safe reproduction and recommended mitigation. Never include actual secrets, customer data or private workspace links. If a credential is exposed, its owner should revoke or rotate it; deleting a file alone does not remove Git history.

For ordinary non-sensitive bugs, use the normal issue template. No specific response-time commitment is made.
