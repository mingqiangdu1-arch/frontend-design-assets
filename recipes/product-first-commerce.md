# PR-010 · Product-first Commerce Collection

## Visual composition
- Small utility header with visible bag state (not a dense SaaS application shell).
- Product-led hero and original illustrative media, then category/material facet rail or mobile disclosure.
- Card grid prioritizes imagery, name, honest price and an accessible detail action.
- Quick detail modal exposes variants, availability and an explicit simulated bag action.
- Principles footer distinguishes brand storytelling from product decision UI.

Selected Style ID: `commerce-atelier`. Related token: `DT-006`; behavior: `IP-015`. Implemented template: `TPL-006`.

[Runnable prototype](../playground/commerce-atelier/README.md). 
Do not assume React `packages/ui` theme compatibility; this is a standalone static implementation.

## Pre-shipping checklist

Image ownership and alt descriptions, real backend price/availability and variant mapping, customer trust/shipping/tax disclosures, mobile filter reachability, focus/keyboard checks, semantic form interactions, empty/error/loading states, real checkout security and analytics. No payment implementation is present here.
